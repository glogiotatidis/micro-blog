It reads `CHECK_PORT` and optionally `CHECK_HOST` from the environment. It's a statically linked Go binary, or use the tiny Docker image:

```
docker run -e CHECK_PORT=3306 -e CHECK_HOST=db giorgos/takis
```

My colleague Paul built [urlwait](https://github.com/pmclanahan/urlwait/) for the same problem in Python. Neat!
