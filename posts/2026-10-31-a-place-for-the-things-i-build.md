I've wanted a place to drop the things I build as I build them. Not a full blog post every time, just a short entry with a link and maybe a snippet. So here it is: a small timeline.

It's a plain static site, no framework, no runtime build. Posts are Markdown files with a bit of frontmatter; a Python script compiles them into the JSON the page reads. No build to break. Adding an entry is a new file and one command.

If you want to follow along, there's an RSS feed.
