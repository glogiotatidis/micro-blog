About

I'm Giorgos Logiotatidis. This is my personal activity log — a running record of things I build, in the order I build them. Short posts, links, snippets. No comments, no analytics, no ceremony.

sealabs.net has been my corner of the web since 1998. The blog itself is a zero-build static site: a single posts.jsonl file plus a few lines of vanilla JavaScript, hosted on GitHub Pages. Appending one JSON line publishes a new entry.
