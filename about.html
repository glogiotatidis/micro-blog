About

I'm Giorgos Logiotatidis. This is my personal activity log — a running record of things I build, in the order I build them. Short posts, links, snippets. No comments, no analytics, no ceremony.

sealabs.net has been my corner of the web since 1998. The blog itself is a plain static site: Markdown posts with frontmatter compiled to JSON by a small Python script, rendered with vanilla JavaScript, hosted on GitHub Pages. Older posts live under "old blog".
